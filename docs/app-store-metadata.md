## 概要（4000文字以内）

絵や写真を、ゲーム機の画面のようなドット絵に変えるアプリです。

変換はすべて端末内の計算だけで完結します。写真を外部へ送らず、AIの学習もせず、変換した絵の権利も主張しません。通信する広告や解析も入っていないので、機内モードのままでも使えます。

■ 8つの機能

・背景抜き — 外周の色を自動で透過。被写体だけを切り抜くオンデバイスAI（iOS 17以降）と、タップした色を透過する手動の指定も使えます。
・等倍1×透過PNG — 32pxなら32×32のまま。拡大しないので、ゲームやドット絵ツールにそのまま持ち込めます。
・シームレス3×3 — 端をなじませ、並べても継ぎ目の出ないタイルに。3×3のプレビューで確認できます。
・一括変換／パレットロック — 最大8枚をまとめて変換。1枚目の色を残りへ引き継げます。
・1ドット修正 — ペン・消しゴム・スポイトで、変換後のドットを直接描き直せます。20手まで取り消せます。
・差分生成 — 2P色相・白フラッシュ・黒影で、同じ絵の色違いをすぐ作れます。
・スプライトシート結合 — 同じ大きさのフレームを横1列のPNGにまとめます。
・ゲーム機プリセット＋ディザ — FC風16色、GB風4階調、PICO-8、ツクール48px、高精細64px。4×4ディザの入切もできます。

■ 5段階の変換

エッジ保存平滑化 → エッジ優先縮小 → Oklab減色＋ヒューシフト → 孤立点掃除とL字間引き → 1px輪郭線。細い主線や瞳が潰れず、ドット絵らしい粒の揃った絵になります。

■ こんな人へ

ゲームの素材を作りたい、SNSのアイコンをドット絵にしたい、子どもの絵を記念に残したい、絵画作品の色違いを試したい。手軽に試せる道具として作っています。

## 審査メモ

- 外部通信・広告SDK・解析SDKはありません（`PrivacyInfo.xcprivacy` のとおり）。
- 写真はユーザーが選んだものだけを読み、変換結果は「写真への追加」権限で保存します。カメラは端末で撮影した絵をその場で変換する用途です。
- 被写体切り抜きは Vision の `VNGenerateForegroundInstanceMaskRequest`（iOS 17+、オンデバイス）を使います。被写体が無い場合は背景の自動透過へ切り替わります。
- 変換結果の権利はユーザーに帰属し、アプリ側で主張しません。
